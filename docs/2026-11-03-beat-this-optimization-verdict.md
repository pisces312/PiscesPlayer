# Beat This! 裁判式调参：效果评估与搁置决定（2026-11-03）

## 结论：搁置

裁判式调参（Beat This! 上手机当裁判 + 每曲扫参）在 6 首验证曲上**只对个别曲子有效、
提升幅度有限**（超差线合计 −12%，中位数不动）。决定**暂不实施**，方案存档于本文，
将来满足重启条件再做。生成管线维持现状（DSP tracker + 默认参数）。

## 比较效果（`tools/rhythm-lab/experiments/judge_optimize.py`）

每曲 15 候选（tightness × 拟合窗）按裁判选优 + 8 拍段级相位翻转；选择与投票用的就是
评估裁判，故为**收益上界**。判据：网格线 vs Beat This! 的 ≤20 ms 覆盖率 / max（div4）。

| 曲目 | 默认 ≤20%/max | 优化后 | 变化 |
|---|---|---|---|
| 基线《迎着风向前冲》 | 100% / 19.6 | 100% / 19.6 | 已到顶 |
| 就让岁月（广场舞） | 88.1% / 61.7 | **97.2% / 60.7** | 选中 1200/16，开头段收敛（div1 max 243→61） |
| 有生之恋（抒情） | 75.6% / 713.5 | 70.4% / 705.6 | **变差**（见教训 1） |
| 阳光灿烂（流行） | 92.7% / 51.8 | 93.7% / 41.0 | 小幅 |
| 玉盘 Live（合唱） | 91.7% / 35.0 | 91.6% / 34.0 | 翻转修好 div1（p95 241→23.3） |
| 雨落哗声（抒情） | 98.9% / 100.7 | 99.0% / 88.9 | 小幅 |

超 20 ms 的线合计 **662 → 585（−12%）**。收益集中在尾部与坏段落；中位数（5–12 ms）
已贴 Beat This! 的 50 fps 噪声底，任何方案都压不动。

## 两条硬教训（重启时必须遵守）

1. **逐段相位翻转会误伤"裁判数错拍"的段**：有生之恋 20–40 s 翻转后 div1 微升、
   div2/4 下降——该段 div2 网格本来就贴着参考细分网格，是 Beat This! 把拍标记打在
   反拍上。若重启，投票改为**逐段两个相位都试、取总误差小者**（裁判在手直接 argmin），
   不用 bias 启发式；且必须接受"裁判自身约定"的上限。
2. **max 判据会被裁判伪影劫持**：有生之恋 max 全程被 5.76 s 空窗支配，按 max 选参
   捡了芝麻丢了覆盖率（75.6→70.5）。判据改为 **≤20% 覆盖率优先，max 仅次级**。

## 方案存档（重启条件见末）

两阶段方案全文：`tools/rhythm-lab/docs/2026-11-03-2010-beat-this-judge-phone-integration-plan.md`。
概要：阶段一 = torch→ONNX 导出 Beat This!（20.25M / int8 ~20 MB / 手机估 30–90 s/首），
只当参考拍点提供者，验收逐点 <1 ms 对齐 PC；阶段二 = 候选扫参 + 段级相位裁决进生成流程，
模型缺失时整条退回默认行为。

**重启条件**：手动/结构手段（见下）仍摆不平某类歌曲的可听感偏差，且接受"跟 Beat This!
计数"的相位约定；或移动端推理成本显著下降。

## 其他优化方向（按性价比排序）

1. **开头锁定段的结构修复**（免裁判、全曲库受益）：锁定点检测 + 开头段从共识拍长
   反向外推。成因（引入段 DP 锁错 5–7% 速度、局部拟合忠实放大）与三步方案详见
   `tools/rhythm-lab/docs/2026-11-03-pc-lab-alignment-under-20ms.md`
   「开头锁定段：成因与结构修复方案」。预期拿走本轮"选参收益"的大头，成本固定。
2. **链式相位解码替代独立投票**：段相位用 Viterbi/链式平滑（翻转有代价），证据弱的段
   不翻——把"误伤裁判数错拍段"和"假阳性翻转"一起压掉。无裁判也能跑，保守方向。
3. **人耳裁判（手动相位微调）**：生成页提供全局/逐段 ±半拍 nudge。剩下的争议段
   本质是计数约定之争，人耳 2 秒解决，比任何算法都准。
4. **蒸馏小裁判**：用 Beat This! 对无标注曲打伪标签，蒸馏 ~2M 的相位/拍点小模型，
   手机成本近零——这是"存档方案"的轻量替代。
5. **onset 前端升级**（次要）：更好的 onset 检测只影响选音与自洽信号，不解决相位约定。

诚实上限：中位数已到参考噪声底，继续压数字意义有限；实际目标应定为
**"无可听感偏差"**（开头不错拍、无半拍错位），方向 1+3 就能覆盖大部分场景。
