# Provenance

PiscesPlayer is a modified version of [PixelPlayerOSS](https://github.com/PixelPlayerHQ/PixelPlayerOSS),
the FOSS music player maintained by Theo Vilardo ([@lostf1sh](https://github.com/lostf1sh)),
licensed under GPL-3.0-or-later.

This repository began as a GitHub fork of PixelPlayerOSS and is now maintained
as an **independent project**: it is no longer part of the upstream fork
network, ships under its own package name (`com.pisces312.piscesplayer`), and
its release APKs are signed with the maintainer's own key.

## Upstream baseline

- Upstream repository: <https://github.com/PixelPlayerHQ/PixelPlayerOSS>

## Modifications

PiscesPlayer modifications date from 2026-09-08 onward (250+ commits on top of
the shared history). The significant changes are summarized in [NOTICE](NOTICE)
and chronicled in [CHANGELOG.md](CHANGELOG.md) and this repository's git
history. Files that are original work of the PiscesPlayer maintainer carry an
`SPDX-License-Identifier: GPL-3.0-or-later` header noting the authorship.

## Source availability

The complete corresponding source code for every distributed APK is published
in this same repository, tagged with the matching version (e.g. `v1.0.0`), and
is offered from the same place as the binaries (GitHub Releases) at no charge,
in accordance with GPLv3 §6(d).
